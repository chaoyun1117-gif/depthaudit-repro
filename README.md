# depthaudit-repro

Depth-aware detection audit for microbiome–disease associations.

This repository contains the reusable R/Python reproduction bundle for the manuscript:

**Detection failure as a hidden driver of microbiome–disease associations: a depth-aware framework for 21,400 metagenomes**

Contents:
- R bridge: curatedMetagenomicData -> EH_archaea_merged.csv
- Python DepthAudit package
- derived data tables
- figure-generation scripts
- checksums and environment snapshot

The bundle is a mixed R + Python + shell workflow. See README.md inside the zip for details.
